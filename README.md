# TRIPL3 — Prototype 0.2

Demo responsive en español e inglés. Abre `index.html` en un navegador para probar.

## Incluye
- Logo TRIPL3 original en portada, encabezado e icono
- Navegación: inicio, partidos, ligas, favoritos, perfil
- Accesos directos, marcadores ocultables y preferencias persistentes
- Ilustraciones de jugadores **genéricas**; no son fotos oficiales ni representan la identidad de los jugadores
- Datos y resultados de ejemplo (DEMO)

## Publicar gratis como web de prueba
1. Crea un repositorio en GitHub y sube **el contenido** de esta carpeta a la raíz.
2. En Settings > Pages, selecciona Deploy from a branch, main, /(root).
3. Espera el enlace HTTPS que proporciona GitHub Pages.

No es aún una aplicación Android/iOS ni tiene notificaciones reales, usuarios ni datos deportivos conectados. Para publicar en tiendas, migrar a Expo/React Native, sustituir material ilustrativo por imágenes licenciadas y conectar datos autorizados.
